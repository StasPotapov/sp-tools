# sp-tools — правила для агента

Публичный каталог плагинов Claude Code. Здесь только `.claude-plugin/marketplace.json`,
README (en + ru) и лицензия. Кода плагинов здесь нет: каждый плагин живёт в своём
репозитории `~/dev/<имя>`.

- **Origin — Gitea** `forge:home/sp-tools.git`. GitHub `StasPotapov/sp-tools` — push-зеркало
  с `--force`, напрямую туда не пушим.
- **Каталог руками не правим.** Релизы, теги и записи плагинов ведёт скилл `sp-tools`
  (`~/dotfiles/claude/.claude/skills/sp-tools/`): он ставит теги в репозиториях плагинов,
  ждёт их на GitHub и только потом переводит `ref` и `sha` в каталоге.
- **Каждая запись указывает на тег** (`source.ref` = `vX.Y.Z`, `source.sha` = коммит тега).
  Поле `version` в записи не пишем: версия живёт в `plugin.json` плагина.
- **В каталог попадает только публичный на GitHub репозиторий:** ссылку на приватный
  другие люди не установят.
- Новый плагин в каталоге — строка в таблицу обоих README тем же заходом.
- После правки: `claude plugin validate .`.
